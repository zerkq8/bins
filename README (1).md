# مرصد المتداولين — نسخة Vercel

## لماذا فشلت النسخة السابقة

الخطأ `The string did not match the expected pattern` هو رسالة Safari عندما يفشل
تحليل JSON. سببه أن **Vercel لا يشغّل خادم Express**؛ فطلب `/api/top` رجع صفحة
خطأ HTML بدل بيانات، والصفحة حاولت قراءتها كـ JSON.

الحل: تحويل الخادم إلى **دوال Serverless** داخل مجلد `api/` — وهو ما تتوقعه Vercel.

## بنية المشروع الجديدة

```
index.html            الصفحة (تُخدم كملف ثابت من الجذر)
api/top.js            أفضل 10 متداولين
api/search.js         البحث بالاسم
api/trader/[id].js    تفاصيل متداول + آخر 10 صفقات
api/debug.js          صفحة تشخيص — تخبرك بماذا رد به باينس بالضبط
lib/binance.js        منطق الاتصال + بلوك ENDPOINTS
vercel.json           إعداد المنطقة الجغرافية (مهم جداً)
server.js             للتشغيل المحلي فقط
```

## خطوات النشر

1. احذف محتويات المستودع القديم على GitHub وارفع هذه الملفات مكانها.
   **تأكد أن مجلد `api` مرفوع فعلاً** — بدونه ستتكرر نفس المشكلة.
2. في Vercel: المشروع يُعاد نشره تلقائياً بعد الرفع.
3. لا تحدد أي Build Command أو Output Directory — اتركها فارغة (Vercel يتعرف تلقائياً).
4. افتح الرابط.

## قبل أي شيء: افتح صفحة التشخيص

```
https://اسم-موقعك.vercel.app/api/debug
```

تخبرك بثلاثة أشياء مهمة:

| ما تراه | المعنى | الحل |
|---------|--------|------|
| `"status": 200` | كل شيء سليم | لا شيء |
| `"blockedByRegion": true` أو status ‏451/403 | باينس تحجب سيرفرات هذه المنطقة | غيّر `regions` في `vercel.json` إلى `sin1` أو `hnd1` وأعد النشر |
| `"status": 404` أو رد HTML في `preview` | تغيّر مسار باينس | حدّث بلوك `ENDPOINTS` في `lib/binance.js` (الطريقة أسفل) |

**ملاحظة:** `vercel.json` يضبط المنطقة على **فرانكفورت (fra1)**، لأن سيرفرات
Vercel الأمريكية (الافتراضية) محجوبة من `binance.com`. لا تحذف هذا الملف.

## إذا تغيّرت مسارات باينس

1. افتح صفحة Copy Trading في متصفح على الكمبيوتر.
2. `F12` ← تبويب **Network** ← فلتر **Fetch/XHR**.
3. اضغط على أي متداول وراقب الطلبات الجديدة.
4. انسخ المسار وضعه في `ENDPOINTS` أعلى `lib/binance.js`.

لا شيء آخر في المشروع يحتاج تعديلاً.

## التشغيل المحلي

```bash
npm install
npm start      # http://localhost:3000
```

## حدود معروفة

- من يخفي محفظته على باينس تظهر إحصائياته فقط بدون سجل صفقات.
- التحديث كل 45 ثانية للمتداول المفتوح — ليس لحظياً، ولا يصلح للنسخ الفوري.
- نقاط الاتصال غير موثّقة رسمياً، وسحبها قد يخالف شروط استخدام باينس.
